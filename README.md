# Larzus Apps

Site institucional responsivo da Larzus Apps.

## Rotas

- `/` — página institucional
- `/apps/versiculo-do-dia/` — página do aplicativo
- `/privacidade/` — modelo de Política de Privacidade
- `/termos/` — modelo de Termos de Uso

Consulte `GUIA-COMPILAR-NO-PC.md` ou `GUIA-GITHUB-PAGES.md` para publicar.

Antes da publicação, procure por `[` no conteúdo e substitua todos os placeholders.
